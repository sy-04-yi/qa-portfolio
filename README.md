项目二：用户数据资产盘点与质量评估（数据治理实践）
第二个项目为独立的数据治理实践：对 2000 行模拟用户数据完成资产盘点、分类分级、质量评估与整改建议的完整闭环。数据全部为程序随机生成的虚构信息，不对应任何真实个人。
项目
说明
数据规模
2000 行 × 6 字段（姓名 / 手机号 / 身份证号 / 地址 / 消费金额 / 注册时间）
合规依据
《数据安全法》第 21 条分类分级制度、GB/T 35273 个人信息安全规范
使用工具
Excel（COUNTBLANK / SUMPRODUCT+COUNTIF / COUNTIF）、Word
核心方法
数据资产盘点 → 分类分级 → 六性检查 → 问题清单 → 整改建议
交付成果
- user-data-2000.xlsx：含 6 个工作表——用户数据、数据资产盘点表、数据分类分级清单、数据质量六性检查、问题清单、说明页
- quality-assessment-report.md：评估报告在线预览版
- quality-assessment-report.docx：评估报告 Word 版
关键结果
- 资产盘点：13 列模板逐字段统计，用 COUNTBLANK 算空值、SUMPRODUCT+COUNTIF 去重算唯一值、IFERROR 算空值率
- 分类分级：手机号 / 身份证号 / 地址定为敏感个人信息，姓名为个人信息，金额 / 时间为一般数据；配套脱敏与访问控制规则
- 六性检查：完整性、唯一性、准确性、有效性、及时性多维度检查，发现 7 类问题（严重程度高 5 / 中 2），条数全部由公式计算
- 问题清单：逐条列出影响字段、问题条数、占比、严重程度与业务影响
- 整改建议：清洗规则 / 流程制度 / 脱敏方案三方面；并记录了位数校验排除空值以避免重复计数的方法修正
